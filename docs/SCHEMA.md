# Database schema

`channels` and `videos` store the latest public state; `channel_statistics_snapshots` and `video_statistics_snapshots` are append-only history and unique by entity/timestamp. `derived_video_features` keeps separate locally computed data and provenance. `competitor_channels` marks public-only channels. `ingestion_runs`, `api_requests`, `raw_api_responses`, and `alerts` provide operational auditability. The migration also provisions daily Analytics dimension tables (`video_daily_analytics`, `channel_daily_analytics`, `traffic_source_daily`, `geography_daily`, `device_daily`) and support tables for playlists, comments, taxonomy, candidate discovery, experiments, and analysis results. Sensitive OAuth tokens are local files, while `oauth_credentials_metadata` has status/expiry/path only.
